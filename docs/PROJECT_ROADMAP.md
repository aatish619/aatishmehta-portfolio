## Phase 1 — Foundation & Design System

**Goal**: Build the scalable technical foundation.

### Deliverables

- [x] Next.js 15 project initialized
- [ ] Tailwind CSS 3.4.x configured
- [ ] shadcn/ui initialized
- [ ] Design system tokens implemented
- [ ] Typography system (Geist, Inter, Geist Mono)
- [ ] Reusable UI components
- [ ] Animation system (Framer Motion variants)
- [ ] Layout components (Container, Section)
- [ ] Navigation shell (Navbar, Footer)
- [ ] Providers (Theme, Lenis, Motion)
- [ ] SEO foundation
- [ ] Folder structure complete
- [ ] Documentation complete

### Not Included

- No hero content
- No project data
- No experience data
- No portfolio content of any kind
